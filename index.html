¿Qué es GIT?

Es un sistema de control de versiones distribuido, gratuito y de código abierto que permite a los desarrolladores rastrear cambios en el código fuente, colaborar en proyectos y gestionar el historial de modificaciones de forma eficiente.

¿Cómo se crea una rama en un repositorio?

Para crear una rama en un repositorio, se puede usar la línea de comandos con git branch <nombre-de-la-rama> o un comando combinado como git checkout -b <nombre-de-la-rama> para crearla y pasar a ella inmediatamente.

¿Cómo funciona Git?

Git funciona registrando "instantáneas" (commits) del estado del proyecto y usando sumas de comprobación para verificar que los datos no han sido alterados.

¿Para qué sirve el comando git add .?

Sirve para preparar todos los cambios (archivos nuevos, modificados y eliminados) en el directorio actual y sus subdirectorios para la siguiente confirmación (commit).

¿Qué es un commit en Git?

Un commit es una instantánea guardada del estado actual de tu proyecto en un momento específico, similar a un punto de guardado en un videojuego. Crea una versión segura del código que puedes rastrear y volver a visitar en el futuro.
