¿Que es GIT?

es un sistema de control de versiones distribuido, gratuito y de código abierto que permite a los desarrolladores rastrear cambios en el código fuente, colaborar en proyectos y gestionar el historial de modificaciones de forma eficiente.

¿Como se crea una rama en un repositorio?

Para crear una rama en un repositorio, se puede usar la línea de comandos con git branch o un comando combinado como git checkout -b para crearla y pasar a ella inmediatamente.
